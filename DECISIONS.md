# Технічні та продуктові рішення

- Обрано статичний HTML, CSS і vanilla JavaScript, оскільки репозиторій був порожній і наявного framework не було.
- Обрано вбудований Node.js HTTP сервер без package dependencies. Він обслуговує сторінку та приймає заявки на одному origin.
- Lead webhook викликається тільки з сервера. Секретна адреса не потрапляє в клієнтський bundle.
- Відсутній webhook повертає явну помилку. Сервер не зберігає заявку та не показує фальшивий успіх.
- Структура і копірайтинг спираються на `ALISIO_AI_AUDIT_LANDING_UA.md`. Використано нічні фото, Electric Lime для дій і Coral для винятків.
- Не додавали клієнтські логотипи, відгуки, вигадані результати чи показники.
- Рух реалізовано CSS та IntersectionObserver. Контент лишається доступним без JavaScript, а системний reduced-motion вимикає анімації.
- Події аналітики нейтральні до провайдера. Вміст текстового поля не надсилається в `dataLayer`.
- Сторінку конфіденційності додано як маршрут, але її власник має доповнити юридичні відомості перед публічним запуском.
- Три низькодетальні фото зі скриншотів замінено на окремі чисті фото без підписів або інтерфейсного тексту. Hero-композиція залишає ліву зону затемненою для заголовка та показує архітектуру праворуч.
- QR-мінілендинг використовує окремий вертикальний ролик на вузьких екранах і горизонтальний на desktop/tablet. CTA відкривається після повного завершення ролика, відео ховається, а CTA займає його місце як окремий екран.
- Посилання месенджерів лишено в явній конфігурації `qr-config.js`; невідомі адреси ботів/номер WhatsApp не вигадуються.
- Картку «Бронювання та дохід» оновлено фото оператора рецепції з логотипом ALISIO на екрані, без фальшивих метрик або дрібного намальованого інтерфейсу.
