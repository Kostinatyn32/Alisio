# ALISIO AI-аудит готелю

Односторінковий україномовний сайт для залучення готелів на безкоштовний AI-аудит. Проєкт використовує HTML, CSS і JavaScript без сторонніх бібліотек. Node.js сервер обслуговує сайт та передає заявки у webhook.

## Запуск

Потрібен Node.js 20 або новіший.

```powershell
npm run dev
```

Відкрийте `http://localhost:4173`. QR-мінілендинг доступний за адресою `http://localhost:4173/qr`. Для запуску у production використовуйте `npm start` і встановіть `NODE_ENV=production`.

## QR-мінілендинг

Сторінка `/qr` підбирає вертикальний чи горизонтальний ролик за шириною вікна, запускає його без звуку та показує блок запису на безкоштовний AI-аудит наприкінці перегляду. Перед публікацією вкажіть фактичні посилання на Telegram і WhatsApp у кореневому файлі `qr-config.js`. Кнопки лишаються недоступними, доки адреси не налаштовані.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публікує два маршрути одного Pages сайту: основний `/<назва-репозиторію>/` і QR-мінілендинг `/<назва-репозиторію>/qr/`. Build script переписує абсолютні asset URL під базовий шлях GitHub Pages. GitHub Pages роздає лише статичні файли, тому Node endpoint `/api/audit-lead` для форми не працюватиме на цьому хостингу; реальні заявки потребують окремого серверного хостингу або зовнішнього form endpoint.

## Підключення заявок

Скопіюйте `.env.example` до `.env` та задайте `AUDIT_LEAD_WEBHOOK_URL`. URL інтеграції залишається тільки на сервері. Після налаштування webhook сторінка передаватиме JSON з контактами, готелем, кількістю номерів, описом процесу, UTM-мітками та часом заявки.

Поки webhook не задано, сервер повертає зрозумілу помилку конфігурації. Заявка не видається за успішно надіслану та не записується на диск. Перед прийманням заявок перевірте, що webhook налаштований і приймає payload.

## Розгортання

Розмістіть репозиторій на хості з Node.js 20+, встановіть production environment variables і запустіть `npm start`. Сервер слухає порт із `PORT` та обслуговує сторінки `/`, `/ai-audit` і `/privacy`. HTTPS має завершуватися на платформі розгортання або reverse proxy. Встановіть `ALISIO_SITE_URL` у `.env` або середовищі хостингу. Значення використовується у canonical, OG metadata, JSON-LD і sitemap.

## Перед публічним запуском

- Підключити та перевірити `AUDIT_LEAD_WEBHOOK_URL`.
- Оновити політику конфіденційності юридичною назвою оператора, контактами, фактичними одержувачами та строком зберігання.
- Задати публічний домен у хостингу та перевірити canonical і соціальне зображення.
- За наявності аналітики підключити обробник `window.dataLayer`. Події сторінки не містять вільного тексту форми.

Підключені production assets лежать у `public/assets/`. Вихідний брендбук і приватні довідкові документи не входять до публікації.
