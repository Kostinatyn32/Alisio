# Стан проєкту

Останнє оновлення: 2026-09-30

## Статус

Готова повна адаптивна сторінка AI-аудиту готелю. Локальний сервер Node.js без сторонніх runtime-залежностей. Проєкт запускається командами `npm run dev` або `npm start`.

## Готово

- Розпаковано повний брендбук до `brandbook/alisio-night-operations-brandbook/`.
- Створено українську сторінку з усіма основними секціями production brief.
- Підключено логотип, favicon, hero, фотографії секцій, іконки й графічні патерни.
- Реалізовано адаптивну навігацію, форму, inline-перевірки, UTM, FAQ, motion з reduced-motion режимом та події аналітики.
- Додано endpoint заявок із серверним webhook adapter.
- Додано сторінку політики конфіденційності та інструкцію запуску.
- Додано окремий QR-мінілендинг `/qr` з вибором 16:9 або 9:16 відео за шириною екрана, muted autoplay, керуванням звуком, прогресом перегляду, подіями аналітики й фінальним CTA-екраном після повного завершення ролика. Після завершення відео ховається; CTA займає один desktop екран або приблизно до 1,25 mobile екрана.
- За відгуком зі скриншотів замінено hero photo, ілюстрацію карти процесів, фото рецепції та картку бронювань на нові чіткі WebP без вбудованого UI-тексту; у фото бронювань логотип ALISIO на екрані ноутбука.

## Assets

Використовувані production assets скопійовано до `public/assets/`. Повна вихідна бібліотека лишається в теці `brandbook/`.

## Зовнішні інтеграції

- CRM або webhook: endpoint готовий, `AUDIT_LEAD_WEBHOOK_URL` ще треба налаштувати.
- Аналітика: події публікуються через `window.dataLayer`, провайдер не підключений.
- QR-мінілендинг: Telegram та WhatsApp URL треба вказати у `qr-config.js`.
- Canonical, OG metadata, JSON-LD і sitemap формуються сервером на основі `ALISIO_SITE_URL`.
